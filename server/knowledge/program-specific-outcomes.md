# Program Specific Outcomes (PSOs)

The Computer Science and Engineering graduates are expected to achieve the following program-specific outcomes.

## PSO1 – Open Source Technologies

Demonstrate knowledge and practical skills in open-source technologies.

---

## PSO2 – Emerging Technologies

Develop innovative solutions by adapting emerging technologies for industry-oriented applications.

---

## PSO3 – Software Development Life Cycle

Implement Software Development Life Cycle (SDLC) principles for project and product development.
